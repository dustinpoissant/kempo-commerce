# kempo-commerce

Carts, orders and checkout for [kempo](https://github.com/dustinpoissant/kempo): it sells what
[kempo-products](https://github.com/dustinpoissant/kempo-products) lists, takes payment through
[kempo-payments](https://github.com/dustinpoissant/kempo-payments), and uses
[kempo-tax](https://github.com/dustinpoissant/kempo-tax),
[kempo-store-credit](https://github.com/dustinpoissant/kempo-store-credit) and
[kempo-credits](https://github.com/dustinpoissant/kempo-credits) when they are installed.

> **Status: not built.** This repository is a boilerplate that holds the plan. Nothing here runs
> yet. [PLAN.md](./PLAN.md) is the design and the list of things other extensions are already
> waiting on this one for — read it before building anything.
